# Utils Directory (`src/utils`)

This directory contains pure utility functions, formatters, and reusable helper routines that do not contain UI logic.

### Recommended Utilities:
- `crypto.js`: Helper functions for cryptographic hashing, signature checking, and checksum verifications.
- `formatters.js`: Date formatting, credential ID masking, and string manipulation helpers.
- `constants.js`: Application-wide constants (e.g., verification statuses: `VALID`, `REVOKED`, `EXPIRED`, `PENDING`).
- `validators.js`: Input validation logic for credential formats (e.g., W3C Verifiable Credentials schema, JSON-LD schemas).
