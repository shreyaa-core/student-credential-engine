# Pages Directory (`src/pages`)

This directory houses route-level page components. Each page represents a full screen or distinct view in the application.

### Recommended Pages:
- `VerifyCredentialPage.jsx`: Public portal where verifiers/employers input a credential ID, upload a verifiable credential file, or scan a QR code to verify validity.
- `StudentDashboardPage.jsx`: View where students view their earned micro-credentials and shareable verification links.
- `IssuerPortalPage.jsx`: Administrative view for academic institutions to issue and sign new micro-credentials.
- `NotFoundPage.jsx`: 404 fallback page for unmatched URLs.
